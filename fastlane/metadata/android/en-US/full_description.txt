<p>A grocery and TODO list app that keeps your lists in a plain Markdown file. Because the data is an ordinary <i>.md</i> file that you pick, you can keep it in a synced folder (Nextcloud, Syncthing, …), edit it on a computer, and the app picks up the changes when it returns to the foreground and every few seconds while it is open.</p>

<p>The app has no internet access, no ads and no tracking. Your lists stay in the file you chose.</p>

<p><b>Features</b></p>
<ul>
<li><b>Markdown storage</b>: one file holds any number of lists. Each list is a <i>#</i> header followed by task-list items (<i>- [ ] Milk</i>).</li>
<li><b>Three item states</b>: tap a box to cycle new → done → failed.</li>
<li><b>Quick entry</b>: Enter adds an item, Enter on an empty item starts a new list, Backspace at the start of an item joins it to the one above, and in an empty list name joins the list up. Pasting several lines adds many items at once.</li>
<li><b>Counts and prices</b>: the + button counts items up (Milk → 2x Milk). End an item with a price and the done items add up to a total under each list, in the number format of your chosen locale.</li>
<li><b>Selection and reordering</b>: long-press to select items; reorder mode lets you drag items and whole lists around.</li>
<li><b>View mode</b>: the lock button at the bottom right locks the lists while you shop: tap anywhere on an item to tick it off, with no editing, deleting or moving by accident.</li>
<li><b>List actions</b>: reset, copy or delete a list; deletes can be undone.</li>
<li><b>Files</b>: open an existing file or create a new one through the system file picker, and switch between recently used files from the title bar.</li>
<li><b>Settings</b>: number format locale, spacing, text size, and light or dark colors (or follow the system).</li>
</ul>
